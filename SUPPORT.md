# Support

Start with the [README](README.md) and the documents in [`docs/`](docs).

## Ask for help

Search existing [GitHub issues](https://github.com/lucas-lepajollec/bunko/issues) first. If the problem is reproducible and not already reported, open a bug report with the commit or image tag, deployment method, sanitized configuration, reproduction steps and relevant logs.

Remove access tokens, API keys, passwords, cookies, private addresses and the contents of the `data` volume before posting.

Bunko does not provide, host or recommend content sources. Questions about a specific extension or website belong to that extension's maintainers.

Suspected vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be disclosed in a public issue.
